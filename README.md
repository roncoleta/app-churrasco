Desenvolvimento do Projeto:
Durante o processo de criação, tivemos o cuidado de respeitar a arquitetura proposta no início do trabalho. Nos preocupamos em não quebrar o código passado pelo professor, garantindo que a base do aplicativo continuasse sólida enquanto expandíamos suas capacidades.

Funcionalidades Iniciais Preservadas:

Estrutura de listagem dinâmica na tela principal.
Modelo de dados unificado para os itens de compra.
Marcação de itens como comprados por meio de caixas de seleção.
Exclusão individual de itens através do gesto de arrastar.
Funcionalidades Extras Implementadas

Para melhorar a experiência de quem usa, adicionamos os seguintes recursos:

Filtros de Visualização: Inclusão de botões seletores no topo da tela que permitem ao usuário filtrar a lista instantaneamente entre "Todos", "Pendentes" ou "Comprados".

Ordenação Automática: Implementação de uma lógica que move os itens já comprados diretamente para o fim da lista, mantendo o que ainda precisa ser comprado no topo.

Validação de Campos: O formulário de cadastro agora valida os dados inseridos, exibindo mensagens de erro em vermelho caso o usuário tente salvar um item sem nome ou com quantidade menor ou igual a zero.

Categorização com Cores: Criação de categorias (Carne, Bebida e Outro). Cada uma adiciona uma borda colorida e uma etiqueta correspondente ao card do item, organizando a lista visualmente.

Gesto Duplo (Swipe para Editar): O comportamento de arrastar o item foi aprimorado. Arrastar para a esquerda continua deletando o item, mas arrastar para a direita abre o formulário inferior preenchido com os dados atuais para edição rápida.

Limpeza em Lote: Adição de um botão de lixeira na barra superior que permite apagar todos os itens cadastrados de uma só vez, exibindo um aviso de confirmação para evitar cliques acidentais.
